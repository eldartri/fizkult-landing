# INTERACTIONS.md — Состояния, анимации, поведение

**Версия:** 2026-06-01. Базовый паттерн — бруталистский: резкие состояния, без плавных «мягких» эффектов кроме коротких transition.

---

## Кнопки

- **Primary (ink bg / red text):** hover — инверсия: фон → red `#C8261A`, текст → beige `#EFE6D6`; `transition: background .15s, color .15s`. active — без сдвига, можно `filter: brightness(0.95)`.
- **На красном фоне (финал, ink bg / red text):** hover — фон → beige, текст → ink.
- Стрелка `→` в тексте кнопки статична (без анимации появления).
- focus-visible: `outline: 3px solid #1A1A1A; outline-offset: 2px`.

## 152-ФЗ согласие (gated CTA)

**Паттерн (реализован в коде, `GatedCTA`):**
- Чекбокс **под кнопкой** (не click-wrap, явный), `accent-color: #C8261A`.
- Пока не отмечен → кнопка `disabled`, `opacity: 0.4`, `cursor: not-allowed`.
- Отмечен → кнопка активна (`opacity: 1`), ведёт в deep-link (см. DEEPLINKS).
- Текст согласия: ink `#1A1A1A`, mono 11px, ссылка «Политика обработки ПДн» — underline, ведёт на `/privacy`.
- Применяется к **Hero CTA** и **Финальному CTA** (точки входа в подключение Garmin/Strava). Pro CTA («Оформить Pro») ведёт в оплату — согласие на данные там не требуется.
- Состояние согласия можно поднять в общий стейт/локалсторадж, чтобы не просить повторно на одной сессии (опционально для Frontend).

## Карточки архетипов

- Статичны (демо-данные). На hover опционально: лёгкий подъём `transform: translateY(-3px)` + жёсткая тень `6px 6px 0 #1A1A1A` (бруталист-shadow, без blur). Без обязательности.
- Живой индикатор: точка в штампе `АНАЛИЗ · 90Д` — `@keyframes blink` 1.6s.

## Блоки «Что внутри»

- Статичны. Hover опционально — сдвиг рамки/тени как у карточек. Telegram-мок внутри статичен.

## Шаг «Алгоритм читает» (Как работает)

- Чип `АНАЛИЗ · 90Д · 50+ МЕТРИК` — мигающая точка `@keyframes blink` 1.2s. Hero pipeline — точка в `ФИЗКУЛЬТ читает за 60 сек` 1.6s.

## Nav

- `position: sticky; top: 0; z-index: 50`. На mobile (≤760) текстовые ссылки скрыты, остаются лого + CTA `Архетип →`.
- Ссылки якорные: `Архетипы → #archetypes`, `Что внутри → #inside`, `Тарифы → #pricing`. Плавный скролл `scroll-behavior: smooth` (НЕ через `scrollIntoView` в JS — только CSS).

## Скролл-эффекты

- Минимум. Допустимо лёгкое появление секций (`opacity 0→1`, `translateY 16px→0`, 400ms) через IntersectionObserver — опционально, не критично. Никакого параллакса.

## Cookie / consent banner

- Отдельный нижний баннер при первом визите: «Мы используем cookie и обрабатываем ПДн с уведомлением РКН» + кнопки `Принять` / `Политика`. Хранить выбор в `localStorage` (`fizkult_consent=1`). Не блокирует контент, дисмиссится по «Принять».
- Это отдельно от 152-ФЗ чекбокса перед CTA (тот — про передачу данных Garmin/Strava).

## Анимации запрещены

- Никаких градиентных переливов, glow, параллакса, автоплей-видео. Бруталист = резко и статично, движение только в точках-индикаторах.

## Reduced motion

- `@media (prefers-reduced-motion: reduce)` — отключить `blink` и любые появления.
