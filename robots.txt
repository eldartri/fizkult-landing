# 🔴 ПЕРЕД этим файлом Cloudflare подставляет СВОЙ блок — «Cloudflare Managed
# content» (проверено живым запросом 29.10.2026: наш текст начинается только
# после строки `# END Cloudflare Managed Content`). Его политика:
# `Content-Signal: search=yes,ai-train=no,use=reference` и `Disallow: /` для
# роботов, которые собирают материал на обучение моделей, — GPTBot, ClaudeBot,
# Google-Extended, Applebot-Extended, CCBot, Bytespider и ещё два десятка.
# Роботы ПОИСКА среди ИИ там не закрыты, то есть в ответы ChatGPT, Claude и
# Perplexity мы попадаем.
#
# Поэтому здесь разрешены ровно те, кого Cloudflare не закрывал. Писать
# `Allow: /` напротив закрытого им робота нельзя: два правила на один адрес
# разные роботы разбирают по-разному — одни берут менее строгое, другие
# первую подошедшую секцию, — и файл начинает означать разное у разных
# читателей. Один внятный ответ дороже спорного разрешения.
#
# Нужно пускать и обучающих (это согласие отдать тексты сайта в обучение
# моделей) — это переключатель в панели Cloudflare, доступ к ней только у
# владельца. Тогда же снять этот комментарий и дописать сюда их секции.
#
# Имена сверены 29.10.2026 по документации самих компаний, а не по подборкам
# в блогах: developers.openai.com/api/docs/bots · support.claude.com
